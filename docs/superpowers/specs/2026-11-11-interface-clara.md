# Mini Juiz — interface clara e moderna

Direção escolhida pelo usuário: visual claro e moderno. A proposta usa fundo cinza suave, superfícies brancas, azul como destaque e tipografia de sistema, sem dependências externas.

Abordagens consideradas: evoluir a arena escura existente ou criar um painel claro. O usuário escolheu o painel claro; preservamos a estrutura de aplicação e as funcionalidades existentes.

Organizar navegação, resumo de submissões, enunciado, editor, histórico e workers com hierarquia consistente. Navegação por âncoras reais, editor com espaço confortável e upload acessível. Manter IDs consumidos pelo JavaScript e dados reais da API. Adaptar colunas e navegação para celular. Não alterar backend, protocolo de correção ou implantar em outro serviço.

Validar sintaxe JavaScript, suíte existente, integridade dos vínculos DOM e, se disponível, renderização em navegador em desktop e celular.
